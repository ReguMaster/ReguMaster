<p align="center">웹 개발을 하고, 취미로 게임과 도구를 만들어요.</p>

<br />

### 💻 이런 개발을 해요

- **Node.js · React**로 웹 서비스의 백엔드와 프론트엔드를 개발해요.
- 앱·관리자·판매자 서비스처럼 서로 연결된 기능과 데이터를 다루고 있어요.
- **MySQL · Sequelize**를 사용하고, DB 구조와 코드가 일관되게 맞물리는 데 관심이 있어요.
- 직접 쓰다가 불편한 점이 생기면, 고치거나 작은 도구로 만드는 걸 좋아해요.

### 🤖 요즘 관심 있는 것

- **AI 코딩과 개발 자동화** — Claude Code를 활용해 반복 작업을 줄이는 방법을 실험해요.
- **로컬 LLM** — 직접 모델을 실행해 보고, 도구나 게임에 연결하는 데 관심이 있어요.
- **게임 시스템** — Garry’s Mod를 커스터마이징하고, 브라우저에서 즐길 수 있는 리듬게임도 만들어요.
- **NPC 행동** — 정해진 동작만 반복하기보다 상황에 반응하는 캐릭터를 구현해 보고 싶어요.

### 🛠️ 만들면서 신경 쓰는 것

- 실제로 사용할 때 편한지 살펴요. 작은 조작이나 화면 배치도 자주 다듬어요.
- 버그가 생기면 증상과 재현 조건부터 확인하고, 원인을 찾아 수정하려고 해요.
- 기능을 추가할 때는 권한 처리와 입력값 검증, 데이터가 제대로 이어지는지도 함께 확인해요.
- 나중에 다시 고치기 쉽도록 변경을 기능별로 나누고, 수정 이유를 기록하려고 해요.

### 🌌 코딩 밖의 취향

- 게임을 플레이하는 것도, 마음에 드는 시스템을 직접 만들어 보는 것도 좋아해요.
- **우주·신비·몽환적인 분위기**를 좋아하고, 게임 UI의 색감과 연출에도 관심이 많아요.
- 귀여운 캐릭터와 고양이를 좋아해요. 캐릭터의 표정이나 작은 디테일을 보는 것도 즐거워요.
- **자동차와 드라이브**도 좋아해요. 운전 감각부터 정비와 세차까지 관심이 있어요.
